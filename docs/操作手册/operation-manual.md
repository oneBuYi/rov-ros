## 1. 首次部署

首次部署是将水下机器人从开箱到系统就绪的完整流程。完成本章后，操作员即可开始执行巡检任务。

### 1.1 开箱检查

在启动系统前，按以下清单逐项确认：

- [ ] **水下机器人电池**：已充满或电量充足
- [ ] **水下机器人水密**：舱盖密封圈清洁无杂物，舱盖锁紧
- [ ] **线缆连接**：水下机器人与岸上笔记本之间的线缆完好
- [ ] **摄像头**：镜头清洁无遮挡
- [ ] **UGPS 基站**：岸上 UGPS 基站已部署并通电

### 1.2 系统接线

水下机器人通过线缆与岸上操作员的笔记本连接，实现控制指令和数据的传输。

| 条件 | 要求 |
|------|------|
| 笔记本 | 任意操作系统（Windows / macOS / Linux），有浏览器 |
| 浏览器 | Chrome / Edge / Firefox 等现代浏览器 |
| 网络 | 笔记本通过网线连接水下机器人（IP：192.168.137.100） |

接线步骤：

1. 将线缆一端连接水下机器人
2. 将线缆另一端（网口）连接笔记本
3. 确认 UGPS 基站已通电

线缆分为电力线和信号线，接线说明如下：

**电力线** — 为水下机器人供电，三芯接线：

![电力线接线](材料/图片/电力线.jpg)

- 红色接**火线**
- 黑色接**零线**
- 蓝色接**地线**

**信号线** — 水下机器人与地面控制中心的通信连接：

![信号线接线](材料/图片/信号线.jpg)

- 两根黄绿色信号线，无极性，可反接

### 1.3 上电启动

水下机器人上电后系统**自动启动**，无需手动操作。等待约 **30 秒**后，在笔记本浏览器中打开控制页面。

若系统未能自动启动（浏览器无法打开页面），将水下机器人**断电重启**即可。

### 1.4 打开控制页面

1. 在笔记本浏览器地址栏输入：`https://192.168.137.100:8000`
2. **首次访问**会弹出安全警告（自签名证书），点击 **"高级" → "继续访问（不安全）"** 即可。此后浏览器会记住信任。
3. 页面加载后，操作员将看到地面控制中心主界面。

![证书警告页面](材料/图片/browser-cert-warning.png)
![点击"高级"后显示"继续访问"](材料/图片/browser-cert-advanced.png)

### 1.5 界面导览

地面控制中心 Web 界面是操作员与水下机器人交互的唯一入口。了解各区域的功能是后续操作的基础。

![地面控制中心主页全貌](材料/图片/gcs-main-overview.png)

| 编号 | 区域名称 | 做什么用 |
|------|----------|----------|
| ① | **视频画面** | 实时水下摄像头画面，观察池壁状态和水下环境 |
| ② | **遥测面板** | 实时数据：深度、航向、GPS、当前/目标网格、目标距离、深度偏差 |
| ③ | **网格面板** | 输入目标网格行列号，查看当前位置与目标网格距离 |
| ④ | **摇杆操控区** | 游戏手柄操控（浏览器界面显示为虚拟摇杆） |
| ⑤ | **控制面板** | 在线调节 PID 参数，设定定深/定航目标值，开关灯，调节电机增益 |
| ⑥ | **状态栏** | 连接状态、定深/航向锁定状态、经纬度、偏航角、PID 输出 |

以下对各区域做简要说明，详细操作见第 2 章。

**视频画面** — 视频画面为全屏显示，水下摄像头的 MJPEG 实时画面铺满整个浏览器窗口。遥测面板、网格面板、摇杆操控区、控制面板、状态栏等组件叠加在视频画面之上，延迟约 1-2 秒属于正常现象。

**遥测面板** — 显示水下机器人的运行状态数据：

| 指标 | 含义 | 所属面板 |
|------|------|----------|
| 深度 (Depth) | 当前水深（m），正值向下 | 遥测面板 |
| 航向 (Yaw) | 当前朝向（°），0=正北 | 遥测面板 |
| 纬度 (Lat) / 经度 (Lon) | WGS84 坐标 | 状态栏 |
| 垂直 PWM | 深度 PID 推力输出（-100~100），正值=上升 | 遥测面板 |
| 偏航 PWM | 航向 PID 转向输出（-100~100），正值=右转 | 遥测面板 |
| 当前网格 | 水下机器人最接近的网格编号（R行C列） | 网格面板 |
| 目标网格 | 任务设定的目标网格编号 | 网格面板 |
| 目标距离 | 水下机器人到目标网格的水平距离（m） | 网格面板 |
| 深度偏差 | 当前深度与目标网格深度的差值（m） | 网格面板 |

**网格面板** — 输入目标网格行列号，查看当前位置与目标网格的距离和深度偏差。

**摇杆操控区** — 浏览器界面提供虚拟摇杆，操作逻辑与游戏手柄一致：

| 操控端 | 控制功能 | 说明 |
|--------|----------|------|
| **左摇杆** | 前进/后退、左转/右转 | 上下 = 前进后退，左右 = 偏航旋转 |
| **右摇杆** | 上升/下降、左横移/右横移 | 上下 = 升降，左右 = 横移 |

> 实际操控时以游戏手柄为主，虚拟摇杆在浏览器界面上作为备选。两者操控逻辑完全相同。

![物理手柄按键功能](材料/图片/手柄.png)

摇杆信号中断超过 **500ms** 时，系统自动发送零值指令，电机停止，防止失控。恢复操作后自动恢复控制。

开关灯、调节电机增益的按钮在**控制面板**中操作（见下方控制面板说明）。

**控制面板** — 在线调整深度/航向 PID 的 Kp/Ki/Kd，开关灯，调节电机增益。修改参数后点击 Apply 即时生效。

**状态栏** — 显示连接状态（已连接/未连接）、Arm 状态（已解锁/已锁定）、定深锁定和航向锁定指示灯、经纬度、偏航角、PID 输出值。

### 1.6 确认系统就绪

页面加载后，逐一检查：

| 检查项 | 正常状态 | 异常处理 |
|--------|----------|----------|
| **连接状态** | 状态栏显示"已连接" | 断电重启水下机器人 |
| **视频画面** | 实时水下画面显示 | 检查摄像头连接 |
| **深度数据** | 深度数值正常 | 等待飞控初始化 |

![启动就绪后的完整界面](材料/图片/gcs-status-ok.png)

全部检查通过后，系统已就绪，可以开始执行巡检任务。

## 2. 日常巡检

日常巡检是操作员最常执行的场景，完整流程如下：

```
      巡检前准备
         │
         ▼
    Arm 解锁
         │
         ▼
  吊放下水
         │
         ▼
  开启水下定位
         │
         ▼
  设定定深 + 航向锁定
         │
         ▼
  设定目标网格
         │
         ▼
  导航至目标点（看遥测数据）
         │
         ▼
  到达目标 → 观测/记录
         │
         ▼
  下一网格（重复）或 返航关机
```

以下各节按此流程逐一说明。

### 2.1 巡检前准备

此步骤与首次部署的检查和启动流程一致，简列如下：

1. 确认电池、水密、线缆、摄像头、UGPS 基站状态正常（详见 §1.1）
2. 水下机器人上电，等待约 30 秒
3. 浏览器打开 `https://192.168.137.100:8000`
4. 确认连接状态、视频、GPS、深度数据正常（详见 §1.6）

> 若此前已完成首次部署且未断开连接，可直接从上一次关闭后的状态继续，跳过大部分准备步骤。

### 2.2 Arm 解锁

Arm（解锁）启用飞控电机输出，水下机器人才能响应操控。

- 点击状态栏的 **"Arm"** 按钮
- 状态栏显示 **"已解锁"** 表示 Arm 成功
- 若无法 Arm，断电重启水下机器人，等待约 30 秒后重试

> ⚠️ **注意**：Arm 后水下机器人立即响应摇杆指令。在水面以上不要推动摇杆，防止电机空转。

![Arm 解锁前（绿色 Arm 按钮）](材料/图片/disarmed-state.png)
![Arm 解锁后（红色 Disarm 按钮）](材料/图片/armed-state.png)

### 2.3 吊放下水

Arm 后，使用吊机将水下机器人吊放入水。入水后，通过虚拟摇杆操控水下机器人移动到目标区域。摇杆各轴含义及功能按钮说明见 §1.5 界面导览中摇杆操控区的介绍。

![吊放下水](材料/图片/吊放下水.jpg)

**安全保护：摇杆超时** — 如果摇杆信号中断超过 **500ms**，系统自动发送零值指令（x=0, y=0, z=0, r=0），电机立即停止。操作员恢复操控后自动恢复控制。此保护用于防止通信中断时水下机器人失控。

### 2.4 开启水下定位

吊放下水后，开启水下定位设备（UGPS）以获取水下机器人的实时位置。

**操作步骤：**

1. 打开 SeaTrac PinPoint 软件
2. 进行相应设置，连接水下机器人

![UGPS 开启步骤一](材料/图片/ugps1.png)
![UGPS 开启步骤二](材料/图片/ugps2.png)

3. 确认定位成功开启

![UGPS 开启成功](材料/图片/ugps3.png)

### 2.5 设定定深

定深功能使水下机器人自动维持在设定的目标深度，无需手动调节升降杆。

**操作步骤：**

1. 在 控制面板的深度控制区，输入**目标深度值**（米，正值 = 水下深度）
2. 点击 **"Set Depth"** 按钮
3. 状态栏 **"Depth Hold"** 指示灯亮起，系统开始自动维持深度
4. 要**关闭定深**：点击 **"Toggle Hold"** 按钮，恢复手动升降控制
5. 要**以当前深度为新目标**：先关闭再打开 Toggle Hold，系统自动将当前深度设为目标值

![深度定深已激活（目标 0.7m）](材料/图片/定深.png)

### 2.6 设定航向锁定

航向锁定使水下机器人自动维持在设定的朝向角度，无需手动调节偏航。

**操作步骤：**

1. 在 控制面板的航向控制区，输入**目标航向值**（0° ~ 360°，0° = 正北）
2. 点击 **"Set Heading"** 按钮
3. 状态栏 **"Heading Hold"** 指示灯亮起
4. 关闭/切换方式与定深相同（"Toggle Hold" 按钮）

![航向锁定已激活（目标 100°）](材料/图片/定航.png)

定深和航向锁定可同时开启。开启后操作员只需操控 X/Y 横移和前进，深度和朝向由系统自动保持。

### 2.7 设定目标网格

定深和航向锁定开启后，水下机器人已稳定在目标深度和朝向。接下来设定巡检的目标网格。

池壁检测区域被划分为网格，每个网格点有唯一的**行号-列号**编号：

![网格全览](材料/图片/网格全览.png)

![网格坐标系示意图](材料/图片/网格.png)

- **行号 (Row)**：0 = 最靠近水面，数字越大越深
- **列号 (Col)**：0 = 最左，数字越大越靠右
- 每个网格点已预设有 GPS 坐标和深度值（由技术人员预先配置）

**操作步骤：**

1. 在网格面板输入**目标行号**（Row）和**目标列号**（Col）
2. 点击 **"设定"** 按钮

![网格设定](材料/图片/网格设定.png)
![目标网格距离](材料/图片/目标网格距离.png)

3. 遥测面板立即显示：
   - **目标网格**：如 "R0C3"（第 0 行第 3 列）
   - **目标距离**：水下机器人当前位置到目标的水平距离（m）
   - **深度偏差**：当前深度与目标深度的差值（m）

### 2.8 导航至目标点

设定目标网格后，参照遥测面板的两个关键数据操控导航：

| 关键数据 | 目标值 | 说明 |
|----------|--------|------|
| 目标距离 | 越小越好，< 0.5m 判定到达 | 通过 X/Y 摇杆水平移动缩小 |
| 深度偏差 | 越小越好，< 0.2m 判定到达 | 由定深自动保持（见 §2.5），偏差过大时需调整 |

**操作要领：**

1. 观察**目标距离**数值，操作 X/Y 摇杆向目标方向移动
2. 观察**深度偏差**，若偏差持续偏大，检查定深设定或重新设定深度
3. 同时满足以下条件时，**到达目标指示灯**亮起：
   - 水平距离 < 0.5m（可配置）
   - 深度偏差 < 0.2m（可配置）

![前往目标网格](材料/图片/前往目标网格.png)
![到达目标网格](材料/图片/到达目标网格.png)

另外，遥测面板显示**当前网格**的自动识别结果，即使未设定目标网格，也可用于快速定位水下机器人所在区域。

### 2.9 观测与记录

到达目标网格后：

1. 观察**视频画面**，查看池壁状况（裂缝、附着物、结构完整性等）
2. 可微调摇杆以获取更清晰的观察角度

> 视频以 MJPEG 推流，延迟约 1-2 秒属正常。若画面长时间冻结，刷新页面。

点击**记录**按钮可保存当前遥测数据（CSV）和截图（JPG）：

![选择数据保存位置](材料/图片/选择数据保存位置.png)
![保存数据内容](材料/图片/保存数据内容.png)
![点击记录](材料/图片/点击记录.png)
![记录成功](材料/图片/记录成功.png)

记录的文件可在资源管理器中查看：

![资源管理器中的记录文件](材料/图片/记录数据.png)

### 2.10 继续下一网格

当前网格观测完成后，重复 §2.7 - §2.9：

1. 设定下一个目标网格（如当前 R0C0 → 下一格 R0C1）
2. 导航至目标点
3. 观测与记录

**典型巡检路线**（池壁从水面线向下，自左向右逐列）：

```
R0: C0 → C1 → C2 → C3 → C4 → C5
R1: C0 → C1 → C2 → C3 → C4 → C5
R2: C0 → C1 → C2 → C3 → C4 → C5
...（逐行向下）
```

实际巡检范围根据任务需求选择特定的行列范围。

### 2.11 返航与关机

完成巡检任务后，按以下顺序关闭系统：

| 步骤 | 操作 | 说明 |
|------|------|------|
| **1. Disarm** | 点击 **"Disarm"** 按钮 | 锁定电机，防止误操作 |
| **2. 关闭浏览器页面** | 关闭标签页即可 | 无需数据保存 |
| **3. 水下机器人断电** | 出水后断开电池 | 先出水再断电 |

> ⚠️ **注意**：水中 Disarm 会导致失去推力，确保水下机器人处于安全状态后再操作。

**快速重启**：若需重新启动（如更换电池后），水下机器人重新上电即可，等待约 30 秒后刷新浏览器页面。

## 3. 应急处理

### 3.1 通信中断

**现象**：状态栏显示"未连接"，遥测数据冻结，视频停止。

**自动行为**：
- 摇杆超时保护触发（500ms）→ 电机停止
- 定深/航向锁定失效
- 系统每 3 秒自动尝试重连

**应对**：

1. 不要惊慌 — 水下机器人失去指令后自然漂浮（取决于浮力配平）
2. 检查线缆连接是否松动
3. 刷新浏览器页面
4. 若持续无法连接，将水下机器人断电重启

### 3.2 视频画面丢失

**现象**：视频区域黑屏或无画面更新。

**排查步骤**：

1. 刷新浏览器页面
2. 检查摄像头线缆是否松动（需现场人员协助）
3. 视频画面丢失不影响其他功能（摇杆、遥测等仍然正常），可继续操控返航

### 3.3 深度异常

**现象**：定深开启后水下机器人持续上升或下沉，无法稳定在目标深度。

| 可能原因 | 排查方式 | 解决 |
|----------|----------|------|
| PID 参数不合适 | 观察垂直 PWM 是否在 ±100 大幅摆动 | 调整 Kp/Ki/Kd 参数（在控制面板中调整） |
| 浮力配平偏移 | 关闭定深后也持续上浮/下沉 | 物理调整配重，停止操作 |
| 深度传感器异常 | 深度数值跳变或明显不合理 | 断电重启水下机器人 |

### 3.4 遥控器接管

如果操作员使用物理遥控器（如 FrSky），飞控优先响应遥控器信号。

- **切换到遥控器**：直接使用物理遥控器，地面控制中心摇杆输入自动被忽略，遥测数据仍实时显示
- **切回地面控制中心**：关闭遥控器或切换到地面控制中心控制模式，摇杆恢复控制

### 3.5 常见故障速查

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| 浏览器打不开地面控制中心页面 | 水下机器人未上电或网络不通 | 确认上电，检查线缆 |
| 状态栏显示"未连接" | 系统自启动失败 | 断电重启水下机器人 |
| 无法 Arm | 飞控自检未通过 | 断电重启，等约 30 秒后重试 |
| 水下机器人不响应摇杆 | 未 Arm 或电机故障 | 检查 Arm 状态灯 |
| UGPS 数据为 0 | 水下机器人未下水或水声定位未建立 | 确认水下机器人已下水，等待 1-3 分钟定位建立 |

### 3.6 摇杆按钮速查

### 3.7 关键指标参考

| 指标 | 正常范围 | 说明 |
|------|----------|------|
| 深度 | 0 ~ 10 m | 取决于池壁深度 |
| 航向 | 0° ~ 360° | 0°=正北，90°=正东，180°=正南，270°=正西 |
| 垂直 PWM | -100 ~ +100 | 正值=上升，负值=下降 |
| 目标距离 | 0 ~ ∞ | < 1m 接近目标，< 0.5m 到达 |
| 深度偏差 | 0 ~ ∞ | < 1m 接近目标，< 0.2m 到达 |
| 电机增益 | 25% ~ 100% | 默认 50% |
| 定深默认 Kp/Ki/Kd | 100.0 / 40.0 / 80.0 | 在控制面板中调整 |
| 网络地址 | `https://192.168.137.100:8000` | 地面控制中心页面 |
